# CV de Juan Baltasar Martín

Este es un sitio web personal construido con React, Vite y TypeScript para mostrar el currículum de Juan Baltasar Martín. El sitio soporta internacionalización (i18n) usando i18next y react-i18next, permitiendo cambiar entre español e inglés.

## Características

- Diseño limpio, profesional y responsive
- Soporte para español e inglés
- Información profesional, experiencia, educación, habilidades, proyectos y más

## Scripts disponibles

- `npm run dev` — Inicia el servidor de desarrollo
- `npm run build` — Genera la versión de producción
- `npm run preview` — Previsualiza la versión de producción

## ¿Cómo cambiar de idioma?

Haz clic en el botón de cambio de idioma en la parte superior del sitio para alternar entre español e inglés.
